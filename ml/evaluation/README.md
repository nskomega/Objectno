# Проверка локального зрения

Из корня Objectno при запущенном локальном API:

```sh
python3 ml/evaluate.py ml/evaluation/rooms.json --output private/evaluation/rooms.json
```

Снимки должны лежать по путям из манифеста в private/fixtures. Они не включены в Git. Ссылки на оригиналы, авторы, лицензии и SHA-256 записаны в rooms.json; скачивание выполняется отдельно и не происходит во время анализа. Перед первым запуском нужно просмотреть каждый кадр и определить ожидаемый результат.

- Contemporary bathroom.jpg — OKJaguar, [источник](https://commons.wikimedia.org/wiki/File:Contemporary_bathroom.jpg), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
- Bedroom.jpg — Zolinpiero, [источник](https://commons.wikimedia.org/wiki/File:Bedroom.jpg), [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). Фото используется без изменений.

Программа обращается только к loopback Go API, получает отдельную гостевую сессию и отзывает её после проверки. Перенаправления и системный proxy отключены. Отчёт с текстами модели сохраняется только в private/. Фото в отчёт не копируется.

structural_pass означает лишь ожидаемый тип сцены и непустой/отсутствующий план. Это НЕ принятие качества: quality_review остаётся pending до ручной проверки соответствия фото и пожеланию, пригодности материалов и отсутствия выдуманных деталей.

Первые результаты prompt 8: спальня распознана, но вентилятор назван ветрогенератором, а сохранение дерева нарушено предложением покраски. Ванная сначала отклонялась из-за JPEG/MPO; после исправления декодируется, но генерация плана всё ещё не прошла проверку. Модель не принята для продукта.
