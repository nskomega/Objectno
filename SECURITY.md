# Безопасность

## Сообщение об уязвимости
Если нашли уязвимость в Objectno, не открывайте публичный issue с эксплойтом. Напишите владельцу репозитория через GitHub Security Advisories или личное сообщение аккаунту [nskomega](https://github.com/nskomega).

## Что учитывать
- Локальный MLX-воркер и Go API слушают только localhost и не являются публичным сервисом.
- Веса моделей и пользовательские фотографии не должны попадать в Git.
- Refresh-токены на мобильных платформах хранятся в secure storage; web-сессия живёт в памяти.
