# Objectno — «Объектно»

Помощник по ремонту: от исходного фото и пожеланий до истории работ, обмеров и расчёта материалов. Рабочее название; юридическая и магазинная доступность не проверены.

## Состояние
Flutter-прототип: общая история объекта, фото, локальные предложения по ремонту через Go/MLX, проёмы, план по обмерам и расчёт по норме продукта. Восемь языков и две темы. Go API с гостевыми и обычными сессиями реализован; публичное размещение и магазины ещё не готовы. [Текущий статус](STATUS.md).

## Запуск и проверка
Flutter 3.44.2 / Dart 3.12.2. `flutter pub get`, затем `flutter run -d chrome` для веб-прототипа. Для iOS/Android требуется настроенный нативный toolchain. `dart analyze lib test`, `flutter test`; web-сборка: `flutter build web --release`.
Данные локальные: на web они привязаны к origin браузера; очистка данных браузера удалит их. Синхронизации между устройствами пока нет. Refresh-токен хранится через secure storage на мобильных платформах; web-сессия — в памяти. Без API доступен локальный журнал.

## Публикация
Открытый репозиторий: [nskomega/Objectno](https://github.com/nskomega/Objectno). Выпуск в магазинах готовится. Исходный код приложения распространяется по [MIT](LICENSE). Сторонние зависимости, веса моделей и оценочные фотографии сохраняют собственные лицензии; веса и фотографии не входят в репозиторий. Вся исходная история разработки опубликована в ветке main. Личные материалы поиска работы остаются в соседней папке Работа и не должны попадать в репозиторий приложения.

## Локальная модель и расчёты
[Инструкция запуска](docs/local-analysis.md): Python-воркер и Go API слушают только localhost. Для iOS Simulator задаётся API_BASE_URL=http://127.0.0.1:8088, для Android Emulator — http://10.0.2.2:8088. Обычный телефон не обращается к Mac через собственный localhost; для распространения нужен HTTPS-сервис.

Используются закреплённые открытые веса Qwen3-VL-4B, не собственное обучение. Ответ модели — предварительный черновик; качество на разных комнатах ещё проверяется. Фото не становится обмером. [Расчёт материалов](docs/quantity-calculation.md) использует введённые размеры и норму конкретного продукта. Каталога товаров нет.

Нативная проверка настоящего локального анализа и Keychain: [native-integration.md](docs/native-integration.md). Тест запускает отдельное приложение на симуляторе и сохраняет снимок экрана без ручной съёмки.
