# Objectno — «Объектно»

Рабочее название мобильного приложения для фиксации замечаний при осмотрах объектов: описание, фотографии, статус и отчёт. Название предложено агентом по поручению Михаила; юридическая и магазинная доступность не проверены.

## Состояние
Первый локальный Flutter-прототип: объекты, замечания с фото, статусы и две темы. Авторизация/Go backend и магазинные релизы ещё не готовы. [Текущий статус](STATUS.md).

## Запуск и проверка
Flutter 3.44.2 / Dart 3.12.2. `flutter pub get`, затем `flutter run -d chrome` для веб-прототипа. Для iOS/Android требуется настроенный нативный toolchain. `dart analyze lib test`, `flutter test`; web-сборка: `flutter build web --release`.
Данные локальные: на web они привязаны к origin браузера; очистка данных браузера удалит их. Синхронизации между устройствами пока нет. Секреты в локальную БД не сохраняются; сессии ещё не реализованы.

## Публикация
Создан независимый локальный Git. Планируется открытый GitHub-репозиторий и выпуск в магазинах. Лицензия ещё не выбрана; наличие этой папки пока не означает публикацию open source. Личные материалы поиска работы остаются в соседней папке Работа и не должны попадать в репозиторий приложения.
