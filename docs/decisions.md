# Решения проекта
Обновлено: 31.10.2026. Принято — согласовано или прямо поручено. Предложено — ещё обсуждается.

| Решение | Статус | Причина |
|---|---|---|
| Открытый проект и релизы в магазинах | Принято | Законченное приложение с проверяемым кодом |
| Дизайн-система до реализации UI | Принято | Общие токены, компоненты и состояния |
| Рабочее название «Объектно», папка Objectno | Принято как рабочее | Отражает работу с объектами; доступность бренда не проверена |
| Отдельный Git, changelog и версии | Принято | Независимая разработка и публикация |
| Go, если нужен сервер | Принято условно | Пожелание автора; сервер пока не требуется установленным сценарием |
| Журнал замечаний с фото и экспортом | Предложено | Прикладной сценарий для мобильного приложения |
| Flutter, Material 3, локальная первая версия | Предложено | Небольшой объём законченного сценария |

| Выразительный технологичный интерфейс, чистый насыщенный оранжевый акцент | Принято | Прямое предпочтение Михаила; точные токены ещё подбираются |

| Тёмный графитовый фон первой темы | Принято | Прямое предпочтение Михаила; точные оттенки ещё подбираются |
| Фото + пожелание заказчика → подбор материалов | Продуктовая гипотеза | Идея Михаила для развития; включение в первую версию не решено |

| Обход с фото/видео → план ремонта, спецификация и калькуляция | Продуктовая гипотеза | Расширение идеи Михаила; точность геометрии, объём первой версии и проверка результатов ещё не определены |

| Умеренно скруглённые кнопки и карточки | Принято | Предпочтение Михаила; точные радиусы выбрать на образцах |

| Геометричная технологичная типографика | Принято | Предпочтение Михаила; конкретная гарнитура и начертания ещё выбираются |

| Сбалансированная плотность интерфейса | Принято | Предпочтение Михаила; размеры по содержимому при увеличении текста |
| Поддержка системного уменьшения и увеличения текста | Принято | Прямое требование Михаила; обязательная проверка компонентов и экранов |

| Основная кнопка со сплошной оранжевой заливкой | Принято | Предпочтение Михаила; цвет надписи и состояния ещё уточняются |

| Контурные иконки, выбранные — залитые | Принято | Предпочтение Михаила; конкретный набор пока не выбран |
| Светлая и тёмная темы с начала реализации | Принято | Прямое уточнение Михаила; отменяет прежнее ограничение первой темы только тёмной |

| Тема: как в системе по умолчанию + ручной выбор | Принято | Выбор Михаила; сохранять режим между запусками |

| Поля ввода с обводкой | Принято | Предпочтение Михаила; при фокусе граница оранжевая |

| Карточки: фон + лёгкая тень + деликатная тонкая рамка | Принято | Предпочтение Михаила; подобрать согласованные параметры для обеих тем |

| Плавные и сдержанные анимации | Принято | Предпочтение Михаила; длительности и кривые подобрать на образцах |

| Тёплый молочный фон светлой темы | Принято | Предпочтение Михаила; точный оттенок и сочетаемость проверить на образцах |

| Второстепенная кнопка: оранжевая обводка и текст | Принято | Предпочтение Михаила; без постоянной заливки, контраст проверить в обеих темах |

## Открытые вопросы
Аудитория первой версии; основной сценарий; точные визуальные токены; лицензия; поддерживаемые версии платформ; хранение и управление состоянием.

Новые существенные решения оформлять отдельным ADR, здесь добавлять ссылку. При пересмотре сохранять прежнее решение как заменённое. Не считать предложение принятым только потому, что оно записано.
