# ADR-002: независимый Git, версии и Go-сервер
Дата: 31.10.2026. Статус: принято по поручению Михаила.

## Решения
- Objectno имеет собственный локальный Git с чистой историей только проекта. Корневой репозиторий исключает Objectno из индекса и дальнейшего отслеживания.
- Постепенно публиковать реальные изменения проекта в GitHub. Remote пока не создан; перед первой публикацией выбрать лицензию и проверить состав файлов.
- Вести VERSION, CHANGELOG.md, релизные теги и описание каждой выпущенной версии; коммиты не требуют отдельной версии каждый раз.
- Если функция требует сервера, реализовать его на Go. Потребность в сервере и время его появления определяются продуктовым сценарием; сейчас сервер не создаётся.

## Причины
Независимая история исключает попадание личных документов в публичный проект, облегчает отдельные push и релизы. Go соответствует пожеланию автора и даёт возможность развивать backend-навыки. Сервер добавляется ради функции: синхронизация устройств, общая работа или централизованное хранение; для первой локальной версии это не обязательное условие.

## Последствия
Все команды Git для приложения выполнять из Objectno или с git -C Objectno. Корневой Git сохраняет старую локальную историю, включая ранние копии проектных документов, и остаётся непубличным. Два репозитория не связываются submodule: приложение просто исключено корневым .gitignore.

Подробный процесс версий: ../releases.md.
