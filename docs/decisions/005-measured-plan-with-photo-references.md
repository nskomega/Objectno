# ADR-005: план по обмерам с фотографиями для сверки

Дата: 11.11.2026. Статус: принято по прямому согласию Михаила.

## Сценарий первой версии

1. Пользователь измеряет длину, ширину и высоту прямоугольной комнаты и вводит их в существующую форму обмеров. Высота нужна для расчёта площади стен.
2. Добавляет фотографии с разных углов в историю объекта. Три ракурса — удобная отправная точка, не обязательное количество и не гарантия полноты.
3. По фото вручную определяет двери и окна, выбирает номер стены на плане, вводит измеренные ширину/высоту проёма, отступ слева при взгляде на стену из комнаты и высоту нижнего края от пола.
4. При желании выбирает фото из истории для сверки конкретного проёма. Сохраняются тип и ссылка на запись истории; фото не копируется в обмеры.
5. Приложение показывает план по введённым размерам и вычитает проёмы из площади соответствующих стен. Расчёт материалов использует эти обмеры и норму выбранного продукта.

## Границы

Фотографии служат визуальной справкой. Автоматическое распознавание проёмов, определение масштаба, восстановление плана по снимкам и модель непосредственно на телефоне в этот этап не входят. Не заявлять измеренную точность там, где пользователь не выполнил обмеры. Сложная форма комнаты не подменяется прямоугольной автоматически.

Лист с маркером — отдельный последующий эксперимент: сначала сравнить оценки с рулеткой на нескольких комнатах, затем обсуждать допустимую погрешность. Он не является источником размеров в этой версии.

## Реализация и совместимость

- Существующие размеры комнаты, проверки пересечений/границ и схема сохраняются.
- Проёмы получают `kind` (`door`, `window`, `unspecified`) и необязательный `sourceHistoryId`. У старых записей без типа — `unspecified`, без выдуманного определения двери или окна.
- Ссылку на фото проверяет репозиторий в транзакции: запись должна относиться к тому же объекту в текущей области аккаунта и содержать фото.
- Сохранённый расчёт по-прежнему содержит копию обмеров на момент расчёта; тип и ссылка на фото не изменяют площадь проёма.

## Проверка

Повторное открытие файловой БД, сохранение типа/ссылки/координат, отклонение чужих и отсутствующих фото, прежняя площадь и чтение старых проёмов проверены отдельным Dart smoke-сценарием. Добавлен regression test репозитория и расширен widget-сценарий в обеих темах при 3x текста. Flutter-тесты и визуальная проверка остаются невыполненными: среда не разрешает открыть служебный localhost-сокет.
