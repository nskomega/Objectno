# Нативная проверка локального анализа

Тест использует настоящий Go API, MLX-воркер и iOS Keychain. Модель и API запускаются по [инструкции](local-analysis.md).

Из корня Objectno при доступном Flutter в PATH:

```sh
python3 scripts/test-ios-integration.py UUID_ЗАПУЩЕННОГО_СИМУЛЯТОРА
```

Нужна приватная кухонная фикстура `private/fixtures/coco-397133.jpg`, ранее использованная при проверках модели. Она не входит в репозиторий и не упаковывается в обычное приложение. Тест временно раздаёт только её копию через localhost:8768.

Сценарий: создать объект в изолированной БД, открыть историю, проверить отключённую кнопку без выбора, выбрать светильники, получить реальное предложение, увидеть его на экране, закрыть и повторно открыть БД, восстановить ту же гостевую сессию из Keychain и снова открыть предложение. Проверка не использует камеру/системный выбор фото. Открытие БД и пересоздание корневого виджета не выдаются за полный перезапуск процесса приложения.

Тестовая сборка имеет отдельный bundle ID `dev.objectno.integration`: журнал и Keychain обычного приложения не затрагиваются. После проверки тестовый аккаунт выходит из сессии, временная БД удаляется, приложение теста удаляется с симулятора. Скрипт восстанавливает `FLUTTER_TARGET=lib/main.dart`, в том числе после ошибки.

В Flutter 3.44.2 `IntegrationTestWidgetsFlutterBinding` самостоятельно регистрирует driver extension. Повторный вызов legacy enableFlutterDriverExtension не добавляется. Production main.dart не содержит тестового расширения.

Результаты в игнорируемой папке `output/integration/`: `native-result.json` без токенов и `native-scoped-proposal.png`. Снимок берётся из тестового приложения, поэтому нативная проверка и визуальная оценка не требуют управления заблокированным рабочим столом Mac. Это не снимок системной строки состояния.

Проверено на iOS Simulator 27.2, сборка 44: один сквозной тест прошёл с моделью Qwen3-VL-4B, prompt 10. Подтверждены выбранная категория lighting, реальное сохранение/чтение БД и восстановление Keychain. Нативный снимок просмотрен. Проверки обычных widget/unit-тестов считаются отдельно.
