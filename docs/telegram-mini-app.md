# Telegram-бот и Mini App
Дата: 31.10.2026. Статус: предложение Михаила для дополнительного канала; бот не создан, Mini App не зарегистрирована. Цель App Store/Google Play остаётся в работе.

## Назначение
Запускать «Объектно» внутри Telegram по кнопке бота, подобно привычным встроенным приложениям. Это дополнительный интерфейс продукта, а не функция криптокошелька.

## Предлагаемая схема
- Бот: /start, кнопка открытия, /help. Уведомления о готовом результате — отдельная опция с явным намерением пользователя.
- Mini App: адаптированная Flutter Web-сборка по HTTPS; наши темы и компоненты, отдельная проверка WebView, клавиатуры, safe area, кнопки назад и скорости первой загрузки.
- Go API: общие серверные объекты/замечания, проверка Telegram-входа и сессии; в будущем анализ фото и расчёты.
- Web-статическую часть можно рассмотреть для имеющегося хостинга. Возможность постоянного Go-процесса на тарифе Хост-А не подтверждена; для API нужен подходящий runtime/сервер.

## Авторизация
Передавать сырой Telegram.WebApp.initData на сервер. Сервер проверяет подпись по официальному алгоритму, свежесть auth_date, защищает обмен от повторного использования и только затем создаёт сессию приложения. initDataUnsafe и присланному user id доверять нельзя. Bot token остаётся секретом сервера.
Внутренний user id отделён от Telegram user id; связывать с email-аккаунтом только через подтверждённый вход, не по совпадению имени/username. Схему хранения сессий Mini App проектировать отдельно от Keychain/Keystore мобильного приложения.

## Границы первой проверки
Сначала открыть существующий web-прототип из Telegram, проверить темы, клавиатуру и фото, затем реализовать серверный вход. Локальное IndexedDB не даёт синхронизацию с iOS/Android: общие данные появятся только с Go API и авторизацией.
Веб-прототип на localhost ещё не является опубликованной Mini App. Перед запуском нужны HTTPS URL и бот/настройки BotFather. Пароли и bot token не передавать в чат и не коммитить.

## Перед выбором Flutter Web
Проверить вес/время загрузки и ограничения фото/видео в целевых клиентах Telegram. Переиспользование кода ожидается, но полная совместимость не подтверждена. Если web-клиент слишком тяжёлый, отдельный лёгкий интерфейс можно рассмотреть после измерений.
