# Локальный анализ на Mac

Экспериментальная интеграция открытых весов, не собственное обучение. Нужен Mac с Apple Silicon, Python 3.11, uv, Go и свободная память для модели. Кандидат и ревизия закреплены в ml/download_model.py. Качество не принято для продуктового использования.

Из корня Objectno:

```sh
uv sync --project ml --frozen
uv run --project ml python ml/download_model.py
python3 scripts/run-local-api.py
```

Скрипт собирает Go API, запускает его на 127.0.0.1:8088 и ML-воркер на 127.0.0.1:8091. Секрет сессий создаётся один раз в private/local-auth.key с правами 0600; база и веса также остаются в private/, вне Git. Ctrl+C завершает оба процесса. Если один процесс падает, второй завершается. Порты должны быть свободны.

Для клиента на симуляторе использовать `--dart-define=API_BASE_URL=http://127.0.0.1:8088`. Физический телефон не может обращаться к Mac через свой localhost. Для выпуска нужен отдельный HTTPS-сервер; этот скрипт его не заменяет.

POST /v1/auth/guest с пустым JSON выдаёт обычную отзывную сессию. POST /v1/analysis принимает Bearer access token и JSON с полями photo (base64 JPEG/PNG до 8 МБ), wish, language. Ответ содержит proposal, model, revision, prompt_version и метрики. Фото проходит через память Go и воркера и не сохраняется ими. Отклонённые тексты модели также не записываются. Отдельные CLI-пробы ml/probe.py сохраняют результат только по явно указанному пути.

API проверяет сессию до и после вывода, размер фото и форму ответа. Неподходящая сцена возвращает scene_matches=false без плана. Принятый моделью интерьер ещё не доказывает достоверность наблюдений. Ответ — черновик: без обмеров, количеств материалов, товарных ссылок или инженерных инструкций. В Flutter вывод пока не подключён.
