# Подключения для Flutter-разработки
Проверено 31.10.2026.

1. GitHub уже подключён. Код, история, задачи, PR и релизы.
2. Dart and Flutter MCP — официальный инструмент. Локальная команда `dart mcp-server --help` успешно работает на установленном SDK. Есть анализ, тесты, поиск пакетов, запуск, журналы, runtime errors и hot reload. Наличие команды не означает, что MCP подключён к текущему чату; доступность отдельных runtime-инструментов зависит от приложения и клиента.
3. Context7 — найден доступный плагин, подключение пока не подтверждено. Документация и примеры с привязкой к версии, когда библиотека доступна в индексе. Если не покрыта — официальные docs/API и исходники. Не гарантирует отсутствие ошибок.
4. Figma — найден доступный плагин, подключение пока не подтверждено. Для компонентов, переменных и эталонов; права, тариф и лимиты зависят от аккаунта. Полезен для дизайн-системы, но не обязателен для её хранения в Markdown и Flutter.

Не добавлять backend/БД-сервисы, отдельный memory MCP, браузерную автоматизацию или дополнительные файловые серверы без конкретной потребности. Локальные файлы, Git и команды уже доступны.

Проверенные решения обеспечиваются также простыми ограничениями: минимальные зависимости, фиксация решений, небольшие изменения, анализатор, тесты ключевых сценариев и проверка на устройствах. MCP облегчает доступ к данным и инструментам, но не выбирает архитектуру автоматически.

## Flutter Agent Plugins и Memory MCP
31.10.2026: выполнены `codex plugin marketplace add flutter/agent-plugins` и `codex plugin add dart-flutter@dart-flutter`. Установлен официальный плагин 1.0.7, локальный манифест `.codex-plugin/plugin.json` содержит skills и сервер dart-mcp-server (`dart mcp-server`). Это подтверждение установки, не доступности инструментов в текущем чате.
Ранее зарегистрированный dart_flutter временно оставлен как резерв. После проверки плагина в новом сеансе оставить одно подключение Dart MCP; резерв удалить только после проверки, чтобы не потерять рабочую конфигурацию.
Memory MCP рассмотрен, но не установлен: локальный граф сущностей/наблюдений/связей, не автоматическое сжатие контекста. Для текущего этапа документы Git остаются источником проектных решений. При будущей установке задать отдельный MEMORY_FILE_PATH; хранить только короткие устойчивые сведения и не загружать весь граф на каждом шаге.
