# Состояние Objectno
Обновлено: 31.10.2026.

## Активная цель
Челлендж ежедневных новых версий App Store и Google Play; первая отправка — цель на сегодня. Сборку, отправку, review и публичный выпуск отмечать отдельно. Цель не выполнена. Подробности: docs/daily-release-challenge.md.

## Реализовано локально
Объекты и замечания: описание, фото (камера/галерея), открыто/исправлено, фильтры, каскадное удаление объекта. Сохранение в Sembast. Светлая молочная и тёмная графитовая темы с оранжевым акцентом; системный режим и сохраняемый ручной выбор. Черновые значения токенов реализованы в lib/design_system/theme/objectno_theme.dart; шрифт пока системный, геометричная гарнитура не выбрана.

## Проверено
- dart analyze lib test — без замечаний.
- До локализации flutter test — 9 тестов прошли: сохранность данных после reopen, удаление с каскадом, создание объекта/замечания в обеих темах с масштабом 0.8/1/2/3.
- flutter build web --release — успешно; первичная визуальная проверка в браузере, output/preview/first-prototype.png.
- Нативные фото и системные режимы на устройствах пока не проверены.
- Полного Xcode на машине нет. Полноценный OpenJDK 17 установлен через Homebrew; Android debug-сборка успешна: build/app/outputs/flutter-apk/app-debug.apk. Runtime GoLand не подходит: нет jlink.

## Требуется для релиза
Go API регистрации/входа/refresh/logout/удаления реализован локально и прошёл go test -race и go vet. Flutter-клиент ещё не подключён, публичный API отсутствует. У владельца домен danilovit.pro и тариф reg.ru Хост-А, работа Go-процесса там не подтверждена. Аккаунты магазинов со слов владельца ранее использовались для публикаций, доступ ещё не проверен. Нужны Xcode, проверка подписи/идентификаторов, камера/восстановление image picker после уничтожения Activity, политика и удаление аккаунта, карточки и скриншоты. Remote GitHub, лицензия, теги и магазинные публикации ещё не созданы.
