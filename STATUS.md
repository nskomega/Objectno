# Состояние Objectno
Обновлено: 31.10.2026.

## Активная цель
Челлендж ежедневных новых версий App Store и Google Play; первая отправка — цель на сегодня. Сборку, отправку, review и публичный выпуск отмечать отдельно. Цель не выполнена. Подробности: docs/daily-release-challenge.md.

## Реализовано локально
Объекты и замечания: описание, фото (камера/галерея), открыто/исправлено, фильтры, каскадное удаление объекта. Сохранение в Sembast. Светлая молочная и тёмная графитовая темы с оранжевым акцентом; системный режим и сохраняемый ручной выбор. Черновые значения токенов реализованы в lib/design_system/theme/objectno_theme.dart; шрифт пока системный, геометричная гарнитура не выбрана.

## Слой сессии — 0.1.0-dev.6
Реализованы AuthApi, SessionController и SessionVault: access token в памяти, refresh в FlutterSecureStorage на мобильных платформах, в памяти на web. Сериализована ротация refresh. Журнал поддерживает независимые разделы аккаунтов, гостевые данные сохраняются отдельно. Android: разрешён интернет, отключён backup; HTTP разрешён только debug-манифестом, клиент в release требует HTTPS.

Проверено: dart analyze lib test без замечаний, все 32 Flutter-теста прошли. Новые проверки охватывают совместный refresh, восстановление и отзыв сессии, порядок удаления аккаунта/локальных данных, HTTPS/невалидный ответ и изоляцию разделов с совпадающими ID. Хранилище устройства этими unit-тестами не проверено. Контроллер ещё не подключён к интерфейсу; публичного API и новой нативной сборки нет. Следующий этап — локализованный экран аккаунта и подключение сессии к корню приложения с очисткой навигации при смене пользователя.
