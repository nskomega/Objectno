# UI kit
Версия: 0.1. Дата: 31.10.2026. Статус: предварительная текстовая спецификация для обсуждения, до кода и визуальной проверки. Название «Объектно» и аудитория ещё уточняются. UI kit — библиотека компонентов интерфейса, не Apple UIKit.

## Направление
Выбор Михаила: выразительный технологичный продукт с чистым насыщенным оранжевым основным акцентом. Основа — тёмный графитовый фон, выбранный Михаилом. Точные оттенки и сочетания ещё не выбраны. На экране ясно различимы основное действие и текущая информация. База — стандартные компоненты Material 3 с общей темой; собственные компоненты добавлять для продуктовых сущностей. Первой разрабатывается тёмная графитовая тема. Светлая тема пока не выбрана.

Форма по выбору Михаила: умеренно скруглённые кнопки и карточки. Точные радиусы подбираются на образцах; существующая шкала радиусов ниже остаётся предложением.

Типографика по выбору Михаила: геометричная, технологичная. Конкретная гарнитура, веса и размеры ещё не выбраны; проверить кириллицу, различимость символов, длинные подписи и лицензию перед включением шрифта.

## Токены: предварительные значения
Направление и графитовая основа выбраны пользователем; точные значения ниже — предварительные и требуют адаптации к тёмной теме, не утверждённый бренд. До реализации проверить сочетания цветов и контраст. Использовать семантические имена, а не копировать HEX по экранам.

| Токен | Значение | Назначение |
|---|---|---|
| color.background | Тёмный графитовый; HEX предстоит выбрать | Фон страницы |
| color.surface | Более светлый графит; HEX предстоит выбрать | Поверхности поверх фона |
| color.text.primary | Светлый нейтральный; проверить на выбранном фоне | Основной текст |
| color.text.secondary | Приглушённый светлый; проверить контраст | Дополнительный текст |
| color.action | Чистый насыщенный оранжевый; HEX предстоит выбрать | Основное действие |
| color.onAction | Определить после выбора оранжевого и проверки контраста | Текст на основном действии |
| color.border | #CBD5E1 | Декоративные разделители; значимые границы проверить отдельно |
| color.error | #B91C1C | Ошибка |
| color.error.surface | #FEF2F2 | Фон ошибки |
| color.success | #166534 | Исправлено |
| color.success.surface | #F0FDF4 | Фон успешного статуса |
| color.warning | #92400E | Открыто / требует внимания |
| color.warning.surface | #FFFBEB | Фон предупреждения |

| Группа | Шкала / правило |
|---|---|
| spacing | 4, 8, 12, 16, 24, 32 логических пикселя |
| page.padding | 16 на телефоне; адаптация по доступной ширине |
| radius | 8 для небольших элементов, 12 для карточек, 16 для панелей |
| icon | 20 / 24; размер иконки не равен области нажатия |
| touchTarget | Не менее 48 × 48 логических пикселей как проектный ориентир |
| typography | Геометричная технологичная гарнитура с кириллицей; семейство ещё выбирается; роли через TextTheme |
| heading | 24 / 32, вес 600 — размер / высота строки |
| section | 20 / 28, вес 600 |
| body | 16 / 24, вес 400 |
| label | 14 / 20, вес 500 |
| caption | 12 / 16, вес 400; не использовать для основных действий |

Размер текста не фиксирует высоту контейнера: учитывать переносы и пользовательское увеличение. Цвета и роли должны быть согласованы с ColorScheme; продуктовые статусы при необходимости оформить ThemeExtension. Не строить параллельную тему поверх стандартной без причины.

## Каталог компонентов
Имена в колонке Flutter — предлагаемые точки реализации, существующего кода пока нет.

| Компонент | Варианты / состояния | Поведение | Flutter |
|---|---|---|---|
| Основная кнопка | default, pressed, focused, disabled, busy | Одно основное действие в контексте; busy предотвращает повторную отправку | FilledButton, тема |
| Вторичная кнопка | default, pressed, focused, disabled | Дополнительное действие; текст объясняет результат | OutlinedButton / TextButton |
| Поле ввода | empty, filled, focused, error, disabled | Видимая подпись, ошибка рядом, ввод сохраняется при ошибке | TextFormField |
| Карточка объекта | данные, длинное название, без замечаний | Название, пояснение и число замечаний; вся карточка открывает объект | ObjectCard |
| Карточка замечания | открыто, исправлено, без фото, длинный текст | Заголовок, помещение, статус, необязательная миниатюра; статус не только цветом | IssueCard |
| Статус | открыто / исправлено | Текст + цвет; сам по себе не кнопка | IssueStatusBadge |
| Фильтр статуса | все, открыто, исправлено; selected/unselected | Выбор виден визуально и доступен скринридеру | ChoiceChip / SegmentedButton |
| Добавление фото | empty, attached, unavailable, error | Камера/галерея, повторная попытка; отказ в разрешении объясняется | PhotoAttachment |
| Пустое состояние | нет объектов / замечаний / результатов фильтра | Разные тексты и подходящее действие; не подменять ошибку пустотой | EmptyState |
| Ошибка | ошибка загрузки / сохранения / экспорта | Сообщение с действием восстановления; не терять заполненную форму | ErrorState / сообщение у поля |
| Подтверждение удаления | default, busy, error | Назвать удаляемый объект; явные «Отмена» и «Удалить» | AlertDialog |
| Уведомление | success / undo / error | Критичные ошибки не исчезают без возможности прочитать и исправить | SnackBar / постоянный блок по сценарию |
| Верхняя панель | заголовок, назад, действие | Учитывать safe area и длинные заголовки | AppBar |

Для каждого реализованного компонента добавить путь к коду и пример использования. Стандартный компонент настраивать темой; не создавать обёртку ради имени из таблицы.

## Эталонные экраны
- Список объектов: заголовок, создание, карточки; отдельно пустое состояние.
- Замечания объекта: название, фильтр статуса, карточки, добавление; отдельно отсутствие результатов фильтра.
- Создание/редактирование: помещение, описание, фото, статус и сохранение; клавиатура не перекрывает действие, ошибка не стирает ввод.
Пока это перечень экранов для проверки, не готовые макеты. Точная композиция определяется после продуктового брифа.

## Проверка перед использованием
- Пройти основные сценарии и все применимые состояния.
- Проверить длинные русские названия, переносы, увеличение текста и маленький экран.
- Проверить читаемость и контраст, focus/semantics и области нажатия.
- Проверить клавиатуру, safe area, выход назад и сохранность ввода.
- Визуально сравнить реализацию и эталон; отметить платформу/устройство и результат в STATUS.md.
